How we build

⌂

Self-hosted first

Your data stays on your hardware. Servers and tools run locally with minimal setup and few moving parts.

◐

Private by default

Data stays on hardware you control by default. Where a feature calls an outside service (an AI provider, map imagery, lyrics), the README says so and it is optional where possible.

◇

Lean and dependency-light

Small codebases, open APIs and zero-dependency builds where possible. Easy to audit, easy to run.

▶

Try before you install

Most projects have an in-browser demo with sample data, so you can judge them in minutes.
